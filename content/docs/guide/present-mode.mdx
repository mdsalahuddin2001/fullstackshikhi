## Keys

| Key | Action |
| --- | --- |
| `P` | Toggle present mode |
| `→` / `PageDown` | Reveal next item, then go to the next lesson |
| `←` / `PageUp` | Hide last item, then go to the previous lesson (fully revealed) |
| `Esc` | Exit present mode |

Navigation stays inside the current topic.

## Reveal content step by step

<Reveal each>

- `<Reveal>` — the whole block is one step
- `<Reveal each>` — every list item or child is a step
- `<Steps reveal>` — every `<Step>` is a step

</Reveal>
