---

**CRUD** মানে **C**reate, **R**ead, **U**pdate, **D**elete। প্রায় সব application-এর বেশিরভাগ database কাজ এই চারটির মধ্যেই পড়ে।

| কাজ | SQL |
| --- | --- |
| Create | `INSERT` |
| Read | `SELECT` |
| Update | `UPDATE` |
| Delete | `DELETE` |

## INSERT — data যোগ করা

```sql title="insert.sql"
INSERT INTO categories (name)
VALUES
  ('Electronics'),
  ('Fashion'),
  ('Books')
RETURNING id, name; -- [!code highlight]
```

`RETURNING` Postgres-এর একটি দারুণ feature — নতুন row-গুলোর `id` সাথে সাথেই ফেরত দেয়, আলাদা query লাগে না।

```sql
INSERT INTO products (category_id, name, sku, price, stock, description)
VALUES
  (1, 'Wireless Mouse', 'EL-MOU-001', 850.00, 40, '2.4GHz, 1600 DPI'),
  (2, 'জামদানি শাড়ি', 'FA-SAR-001', 4500.00, 6, 'হাতে বোনা'),
  (3, 'পথের পাঁচালী', 'BK-PTH-001', 450.00, 0, NULL),
  (1, 'USB-C Charger', 'EL-CHG-001', 1200.00, 15, NULL);
```

দাম আর stock-এর সংখ্যাগুলো উদাহরণের জন্য বানানো।

## SELECT — data খোঁজা

<Playground lang="sql">
```sql
SELECT name, price
FROM products
WHERE price < 1000
ORDER BY price DESC
LIMIT 10;
```
</Playground>

SQL যে ক্রমে লেখা হয়, Postgres সেই ক্রমে চালায় না। বোঝার সুবিধার জন্য execution-এর ক্রমটা এরকম:

<Steps reveal>
<Step>
### `FROM` — কোন table থেকে
</Step>
<Step>
### `WHERE` — কোন row গুলো রাখব
</Step>
<Step>
### `SELECT` — কোন column গুলো দেখাব
</Step>
<Step>
### `ORDER BY` — কীভাবে সাজাব
</Step>
<Step>
### `LIMIT` — কতগুলো ফেরত দেব
</Step>
</Steps>

### কাজের কিছু filter

```sql
-- নির্দিষ্ট range
SELECT * FROM products WHERE price BETWEEN 500 AND 1500;

-- কয়েকটি value-র যেকোনো একটি
SELECT * FROM categories WHERE name IN ('Electronics', 'Books');

-- লেখার অংশ দিয়ে খোঁজা (ILIKE = case-insensitive)
SELECT * FROM products WHERE name ILIKE '%mouse%';

-- যাদের value নেই
SELECT * FROM products WHERE description IS NULL;
```

<Callout type="warn" title="NULL = NULL সত্য নয়">
`NULL` মানে "অজানা", তাই `WHERE description = NULL` কোনো row ফেরত দেয় না। সবসময় `IS NULL` বা `IS NOT NULL` লিখুন।
</Callout>

### দুই table একসাথে — JOIN

```sql
SELECT p.name, c.name AS category
FROM products p
JOIN categories c ON c.id = p.category_id
ORDER BY c.name;
```

## UPDATE — data পরিবর্তন

```sql
UPDATE products
SET price = price * 0.9 -- বেশি স্টকের প্রোডাক্টে ১০% ছাড়
WHERE stock > 10;       -- [!code highlight]
```

<Callout type="error" title="WHERE ছাড়া UPDATE">
`WHERE` না দিলে table-এর **প্রতিটি row** পরিবর্তন হয়ে যাবে। Production-এ চালানোর আগে একই `WHERE` দিয়ে একটি `SELECT` চালিয়ে দেখে নিন কোন row গুলো প্রভাবিত হবে।
</Callout>

নিরাপদ অভ্যাস:

```sql
SELECT id, name, price FROM products WHERE stock > 10; -- [!code --]
UPDATE products SET price = price * 0.9 WHERE stock > 10; -- [!code ++]
```

প্রথমে `SELECT` দিয়ে দেখুন, তারপর একই `WHERE` রেখে `UPDATE` চালান।

## DELETE — data মুছে ফেলা

```sql
DELETE FROM products
WHERE stock = 0 AND description IS NULL
RETURNING name;
```

<Callout type="info" title="Foreign key আপনাকে রক্ষা করবে">
কোনো ক্যাটাগরিতে প্রোডাক্ট থাকলে `DELETE FROM categories WHERE id = 1` error দেবে — কারণ `products.category_id` সেই ক্যাটাগরিকে reference করছে। আগের lesson-এর constraint এখানে কাজে লাগছে।
</Callout>
